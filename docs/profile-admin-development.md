# 个人中心与管理后台启动与联调说明

本次完成个人中心、资料编辑弹窗、我的发布、我的接单任务，以及管理员用户、商品、失物和跑腿管理。页面沿用 main 的暖色纸感样式和公共组件。

## 本地体验

环境使用 Node.js 24.x 或符合当前 Vite 要求的版本。在仓库根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

打开终端给出的地址，进入 `/login`。在“先体验个人中心与管理后台”区域选择：

- “以林同学体验”：个人资料、本人三类发布、本人接单与历史记录。
- “进入管理员演示”：用户封禁和解封、内容违规下架和恢复、逻辑删除。

退出后可切换身份；模拟修改保存在当前浏览器，刷新后保留。在登录页点击“重置演示数据”可恢复初始样例。

建议体验顺序：编辑昵称、手机号；在我的商品下架一条记录；在我的失物完结信息；在我的跑腿确认完成；在我的接单确认送达；退出并进入管理演示执行封禁、解封、下架、恢复、删除。

下架、完结、送达、完成、解封和恢复都需确认；封禁、违规下架和删除需要填写操作原因。删除后的记录从列表移除，模拟数据保留删除标记和审计。

## 预置演示场景

- 林同学 ID 2，有 14 条商品发布及不同状态的失物、跑腿记录，可测试分页。
- 商品 101 可下架，103 已由卖家下架，104 为违规下架。
- 失物 201 可完结，205 为待认领，206 已完结。
- 跑腿 302 为林同学接取的进行中任务，可确认送达；303 为林同学发布的待确认任务，可确认完成。
- 跑腿 307 已完成，308 待发布者确认，均保留在接单列表。
- 管理后台有 27 个用户，可以测试翻页、筛选与封禁。管理员账号不提供封禁操作。

测试用户手机号属于虚构样例。演示入口独立于现有登录、注册表单，不代表已完成成员三、成员七的真实认证接口。

## 真实接口切换

开发模式默认启用 `frontend/.env.development` 中的 `VITE_PROFILE_ADMIN_MOCK=true`。

后端接口准备好后，在 `frontend/.env.local` 中设置：

```dotenv
VITE_PROFILE_ADMIN_MOCK=false
VITE_API_BASE_URL=http://127.0.0.1:8000
```

重启开发服务器，使用团队真实登录接口获取的账号身份。演示 Token 不能作为真实认证；关闭模拟模式后，应用会清除残留的演示登录态。

具体请求集中在 `frontend/src/features/profile-admin/api.js`，契约草案见 [个人中心与管理后台接口草案](profile-admin-api-contract.md)。若后端路径或字段有调整，应在接口层统一映射。

普通 `npm run build` 不加载 `.env.development`，默认关闭演示入口。用于正式部署时，确保部署环境与 `.env.local` 没有把 `VITE_PROFILE_ADMIN_MOCK` 设为 `true`。

若需交付静态演示构建，可明确使用：

```bash
npm run build -- --mode demo
npm run preview
```

演示构建仍显示演示提示。生产环境的 `/api` 反向代理按项目部署方案配置，Vite 开发代理不会自动随构建部署。

## 文件组织

- `src/features/profile-admin/`：页面公共逻辑、接口适配、模拟服务、种子数据、列表与详情组件。
- `src/views/profile/`：个人中心、我的发布、我的接单入口。
- `src/views/admin/`：四个管理入口，复用管理组件。
- `src/main.js`、`src/router/index.js`、`src/views/auth/LoginView.vue`、`src/layouts/AdminLayout.vue`：演示登录、私有详情路由和详情导航接入。
- `tests/profile-admin/`：状态流转、资源所有权、管理权限、隐私与逻辑删除测试。

个人中心与管理后台的记录详情使用 `/profile/content/{kind}/{id}` 和 `/admin/content/{kind}/{id}`，按个人权限或管理员权限获取完整记录。返回个人列表时保留对应 Tab；后台详情保留对应菜单高亮。这样可在其他成员的公共详情页尚未接入数据时独立演示。

失物和跑腿的字段及动作参考成员五分支的接口提案，并以补充的 API 通用规范统一分页、错误码和权限边界。成员五分支中的大厅、发布页面尚未合并到本次基线，相关联动需在团队整合时接入同一真实数据服务。

## 验证命令

在 `frontend/` 下执行：

```bash
npm run test:profile-admin
npm run build
```

真实后端的 JWT 校验、手机号唯一约束、分页查询、逻辑删除过滤和管理审计事务，应在后端就绪后另行做接口联调验证。
